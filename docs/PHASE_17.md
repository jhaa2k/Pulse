# Phase 17 — professional editor
Layer list has an alternate timing workspace (not an extra crowded top-level tab), ruler seek, drag move/start/end, fade guides and per-layer selection. Time is clamped to visible span and changes commit once at drag release. Timeline moves layer visibility range only, not keyframes; locked layers protected. Multi-select with filtered select-all, clear, batch show/hide/lock/unlock/center/reset timing/duplicate/delete; cloned keyframes remapped, deleted ones removed, each action one undo step. Property search indexes real section titles and control labels, opens matching whole sections rather than filtering individual controls. Search aliases for repeated section names can produce extra matches. Added guard against new visible composition cycles, best-effort undo commit on inspector disposal. Tests for timing, batch and search. Physical-device UI, GPU, export and full property validation still required; no true overlapping crossfade or signed production release.
