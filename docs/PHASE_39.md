# Phase 39 — motion sampling and measure response
Native motion blur now supports manual spin and zoom, optional effect-transform rotation/scale deltas with angle wrapping, and 13 weighted taps with transparent outside bounds. Relative motion first frame resets; scale is a geometric mean approximation, not optical flow or per-pixel velocity. Gaussian blur has direction and perpendicular spread (zero for directional only). Added frame-time-based smoothing for continuous common transform, opacity, gradient, blur and motion amount bindings; time, shake, keyframe and trigger-pulse measures are kept immediate. Playing-time measure holds the supplied playing clock when paused. Existing effect-transform rotation/zoom option defaults off; new manual values default zero. No exact Avee parity or physical-device GPU verification. Native-only fields are not represented in legacy VIZ. Unit tests cover first-frame reset, angle wrapping, independent smoothing and paused time. Main unchanged.
