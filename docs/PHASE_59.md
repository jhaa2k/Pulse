# Phase 59 — premultiplied color and mask consistency

Neutral image and composition passes retain stored RGB even when additive light exceeds alpha coverage, rather than clipping it through unpremultiply/re-premultiply. Gradient and pattern endpoints are premultiplied before interpolation; color key, aperture and mask coverage attenuate both RGB and alpha. Blurred image borders use the same mask as the foreground, with the corresponding texture orientation. Explicitly restore additive blend equation before mode-specific factors. Existing Alpha/PreMul and Add/AddAlpha compatibility aliases, Screen and Multiply factors remain unchanged; this is not a complete rewrite of blend modes (Multiply on partially transparent destination remains an approximation). Three shader source contract tests added; actual shader compilation and pixel comparison require a GLES device. Main unchanged.
