# Phase 58 — output-scoped composition routing

Iterative dependency traversal resolves the selected output without walking unrelated drafts or recursive stack growth. Preview and export use the same cycle detection; invalid active cycles now report a preview error instead of silently omitting a cyclic source. Missing final composition is rejected before encoding; preview can select a valid draft when no final exists. Resolution changes clear framebuffer allocations and static blur cache together, including unused old-size scratch targets. Four regression tests cover output isolation, self-reference, deep graphs and missing references. This phase does not change blend equations or mask shader semantics, and no device GPU memory measurement has been performed. Main unchanged.
