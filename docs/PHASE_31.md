# Phase 31 — Bar paint and wave detail
54 editable spectrum recipes. Independent inset bar stroke width/color and fill opacity (including hollow bars), height/amplitude/alternating/path gradients and adjustable tip width for rectangular and tapered segments. Secondary segment stroke width/color/fill opacity are independent. Convex fill geometry supports bars, capsules, dots, steps, triangles, diamonds, tapered shapes and related solid styles; line-only segments retain line styling. Tip width applies to rectangular/tapered segments, not rounded capsules/dots. Connected waves now interpolate filled and ribbon surfaces as well as double lines, with curve tension, double-line separation, ribbon thickness and dashed line coverage/count. Dashes apply to the wave stroke, not the filled area. Old projects retain default properties; activating new native features uses the shared creative mesh. .VEX preserves these properties; legacy .VIZ has no guaranteed equivalent. Gallery previews are illustrative, using synthetic audio and approximated colors. Unit tests cover hollow geometry, outline colors, smoothing and wave controls. Real device/export visual validation is still required. Asset manager deferred in favor of user-requested bar/wave customization. Main unchanged.
