# Phase 34 — dynamic spectrum and memory allocation
Playback-position gradient cycling (path gradient mode), signed speed, beat/bass/mid/treble/RMS/peak reactive stroke and color mixing using the selected provider, independent peak shape/width/thickness/offset/color. Audio-reactive values evaluated per frame for preview and export; default configs unchanged. Peak hold timing remains in provider; signed PCM mode has no peak hold. Adaptive buffer growth replaces worst-case rounded-bar allocation and shares capacity with creative geometry; texture cache trims unused internal variants as well as imported textures, retains three core textures, and uses a single end-of-frame trim rather than redundant text eviction. No benchmark or physical-device validation yet. Native VEX fields have defaults; legacy VIZ does not retain them. Main unchanged.
