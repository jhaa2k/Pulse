# Phase 32 — smooth pills and compact editor
Shared adaptive rounded contours replace 16-triangle legacy rounded bars and coarse creative capsules/dots/rounded squares. Curves target 0.1 canvas-pixel chord error, bounded 12–48 quarter segments; enlarged legacy buffer budget. Creative capsules use one convex fill rather than overlapping circles/rectangle. Fullscreen enters aspect-appropriate portrait or landscape orientation, allows rotation inside fullscreen, hides system bars and restores orientation on exit/back. Android may override orientation in some window modes. Runtime window/decor black, opaque preview and lifecycle-aware rendering address white background exposure during Recent Apps; OEM task snapshots require device verification. Compact 42dp search, direct layer reorder arrows, locked/boundary guards and removal of duplicate creative recipes from Add Layer. Main unchanged. Unit tests cover contours and geometry; device screenshot/quality verification pending.

Follow-up: compact search also used in the spectrum gallery and layer preset library; ellipse tessellation uses the same adaptive resolution. Short round bars tested for circular geometry.
