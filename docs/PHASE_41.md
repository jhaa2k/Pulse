# Phase 41 — cinematic project camera and blur optimization
Native ProjectCamera is separate from editor viewport pan/zoom and is disabled by default. Final composition camera uses media position and a selected audio provider for zoom pulse, shake and roll; optional drift and overscan. Overscan conservatively covers a full-canvas source after camera rotation/translation, not individual layers with transparent margins. Dialog stages changes until Apply; one project undo step. Preview and export use the same evaluator; actual audio snapshots may differ. Blur bypasses zero-strength filters and skips perpendicular pass when cross spread is zero, ignores transparent glow passes, releases blur buffers when no active blur layer remains. No benchmark or physical-device rendering validation yet. Camera fields are native VEX only. Main unchanged.
