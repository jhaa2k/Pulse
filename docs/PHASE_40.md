# Phase 40 — advanced particle simulation
Fixed 120 Hz bounded substeps, seven selectable burst signals, hysteresis/cooldown, burst velocity, reactive emission rate, turbulence and emitter-centered attraction/repulsion. Near-camera fade is gradual, zero scale renders nothing; track-position measure receives actual normalized playhead. Particle drawing skips negligible alpha/zero size sprites and shares geometric buffer growth. The fixed-step simulator uses the audio snapshot supplied for each render frame, not sample-by-sample audio; deterministic geometry is tested with constant input at 30/60 FPS. Substeps may increase CPU cost; no performance benchmark or physical GPU validation performed. Existing VEX projects use default controls; legacy VIZ cannot encode native-only additions. Camera movement and effect-stack optimization deferred. Main unchanged.
