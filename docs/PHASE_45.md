# Phase 45 — high-quality rendering
Preview requests 4x/2x MSAA with non-multisampled fallback (low-RAM devices request the original path). Export has optional Smooth Edges, requests recordable 4x/2x/0 EGL configurations and retries context/surface binding. MSAA affects direct surface drawing, not ordinary offscreen FBOs; no guaranteed smoothing of composition-based geometry. High-resolution image texture option allows up to 4096 px for exports above 2048 px on non-low-RAM devices, capped by GPU max texture size; preview and low-RAM export remain bounded. Export texture cache budget increases to 128 MiB in this mode; complex projects can still churn textures. Exact unshifted spectrum bin mapping avoids floating rounding errors. Unit tests cover index mapping and decode limits. Device EGL/codec behavior, actual edge quality, and performance remain unverified. Main unchanged.
