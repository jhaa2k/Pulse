# Phase 46 — smooth blur pipeline
Composition Gaussian blur and image/fit-border blur share GPU separable Gaussian filtering. Large blur uses progressive 2x2 downsampling and bounded dense Gaussian taps; small blur retains full resolution where possible. Fast/Balanced/High quality, two rounds for strong High quality. Radial filters still use 13 taps and may show trails at extreme strength. Composition radius uses 720-pixel reference scaling. Bloom threshold applies at initial filtering only. FBO output is premultiplied RGBA; image orientation tracked; viewport/framebuffer/blend state restored. Downsampling adds isotropic softness to directional filters. Image prefilter occurs before color grading/mask and distortion, intentionally changing the old look. Existing VEX defaults Balanced. No physical device GPU validation or benchmark. Main unchanged.

Follow-up: Image layers receive their own quality selector; a bounded two-role static-image filter cache avoids repeated filtering when a source and all filter parameters are unchanged, invalidates on texture replacement/eviction and never caches dynamic video/composition content across frames. Six one-click blur recipes preserve source composition, mask and audio binding. No GPU performance benchmark.
