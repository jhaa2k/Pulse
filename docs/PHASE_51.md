# Phase 51 — property binding consistency
Unified common audio-reactive inspector with property selector, individual provider, smoothing, threshold, signed position amounts, reset and uniform/ scalar amount behavior. Image tint, creative distortion, text animation and shape bindings now share renderer smoothing. Particle speed uses smoothed continuous measures while time/shake remain substep-evaluated. Transform evaluation rejects non-finite values and honors uniform scale; scale Y track is hidden (not deleted) while uniform. Keyframe clamping supports negative bar height and inspector transform ranges. Existing scalar measures average A/B, unchanged. Legacy TotalTimeAndBack mapped to backward time as a compatibility approximation, not verified Avee parity. Regression tests added. Physical-device inspector and rendering checks remain outstanding. Main unchanged.
