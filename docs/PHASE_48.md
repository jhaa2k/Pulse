Pulse duration is configurable; legacy threshold behavior remains default for existing projects. Enhanced band response blends FFT peak and RMS instead of simple bin averages. New catalog projects enable both options and use pulse-triggered particles. Provider removal now remaps gradient, motion blur and project camera bindings. Native fields only; not exact Avee analysis parity. Tests cover synthetic transients, narrow-band energy and sine response. Real music/device latency and render response not benchmarked.
