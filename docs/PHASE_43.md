# Phase 43 — composition framebuffer lifetime reuse
Dependency-aware slot planner retains each source texture until its last consumer completes, including shared and mask references, then reuses the slot without changing render dimensions. Linear 23-composition chain uses two offscreen composition slots instead of 22; branching graphs may need more. Motion history stays dedicated. Diagnostics show slot count. FBO limits queried from GLES instead of silent 4096 clamping; unsupported sizes fail with a clear message, preview catches IllegalStateException and shows a warning. Surface resize resets motion history. No automatic downscaling of export. Memory estimate excludes driver overhead, and actual device benchmarks and GPU validation remain outstanding. Main unchanged.
