# Phase 22
Project-specific queue storage (private preferences, up to 5000 tracks), selected track ID and last known position restored paused; periodic checkpoint while position changes plus track/pause/seek/edit events; project deletion removes queue. Queue clear and move up/down; playlist rename, delete confirmation and saved ordering; MediaStore library scan off main thread. Export uses selected queue audio rather than stale project URI. Export service gate holds until service teardown and job completion, cancel remains busy during cleanup; MediaStore copy checks cancellation and deletes incomplete new records, verifies pending finalization. SAF output is explicitly truncated and final copy is not interruptible; a write error can leave an incomplete document, which is not automatically deleted because it may preexist. Queue persistence is local, depends on retained URI access, no asset copies or cross-device sync. Checkpoint may lose up to five seconds on abrupt process termination. No physical-device validation or true overlapping crossfade. Tests cover queue selection and position clamping.
