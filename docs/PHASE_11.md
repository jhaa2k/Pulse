# Phase 11 creative studio

Native editable Image-layer creative controls: linear/radial/conic gradients, wave/kaleidoscope/pixelate/zoom distortion, brightness/contrast/hue/temperature, vignette/scanlines/grain. Audio measure drives distortion intensity; track-time phase shared by preview/export. Eight recipes in Add Layer; effects use an available subcomposition or album art. Copy layer with keyframes, paste into current project composition, same-type style copy, transform copy across projects, pivot alignment, reset and canvas color. Copy/paste detects cycles. Reset transform does not clear animation tracks. .VEX retains creative fields; legacy .VIZ export/import does not reproduce these native effects. Shader execution, GLES uniform limits, playback and video export still need physical-device validation. No continuous video decoder or true overlapping crossfade added this phase.
