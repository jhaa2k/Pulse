# Phase 25 — premium UI
Poppins resources for all Material typography styles and display-only uppercase wrapper (editable inputs, stored strings and rendered user text remain unchanged). 23 OFL font families, actual Poppins/Lato/Barlow weights and supported variable weights on Android 8+, static display fonts have limited native weights, older Android and imported fonts may use synthetic weights. Font files/licences sourced during build from pinned Google Fonts revision, packaged offline in APK. Larger consistent 58dp minimum bottom nav with rounded active indicator, horizontally scrollable and auto-scroll to active tab; floating status overlay replaces layout-shifting inline banner. Shared HSV wheel with hue/saturation/value/opacity sliders, original/new checkerboard preview, HEX and staged swatches. Settings defaults 12dp soft corners and 30fps, preserve existing corner preference; diagnostics setting persistence fixed. Preview/export text render share font family and weight; texture cache key includes both. Tests/build/device validation pending; no actual physical screenshot.
