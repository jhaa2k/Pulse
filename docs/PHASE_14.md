# Phase 14 hardware/performance
Sequential MediaExtractor/MediaCodec decoder with hardware preference on API 29+, SurfaceTexture OES to bounded RGBA GPU texture. At most two active codec entries; automatic bitmap frame-sampling fallback on failure. Video layer quality limits 480/720/1280/1920px, sample cadence up to 60 FPS, mode selection. Video source audio remains excluded. Frame selection is nearest forward decoded timestamp, not guaranteed identical to bitmap nearest-frame sampling. Codec timeouts can fall back; no actual hardware device verification. Preview surface resolution 50/75/100% and FPS 15/24/30/60; export resolution independent. HEVC preference chooses supported reported format or H.264; configuration/runtime failures still surface errors. Preflight checks estimated cache space and encoder before PCM decode; displayed output estimate is not a file-size guarantee. Unit tests cover seek, rotation UV, cadence and storage math. Main branch unchanged; true overlapping audio crossfade and on-device tests remain.
