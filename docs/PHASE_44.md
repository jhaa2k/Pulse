# Phase 44 — adaptive preview and texture decode safety
Optional persisted adaptive preview setting uses observed FPS and CPU frame time during active playback. It lowers resolution after three overloaded samples, waits four samples after changes, and recovers after ten comfortable samples. Manual scale is the ceiling; minimum 50%. Applies in all editor preview layouts, never export. Existing preview controls remain. Imported bitmap decoding respects queried texture limits and uses a 1024-pixel cap on low-RAM preview devices; export retains the previous 2048 cap (or GPU limit). Failed image opens are retried after five seconds, bounded map cleared on project change. Fixed 41% default in DataStore and reset path, saved preferences preserved. Unit tests added. MSAA, anti-aliasing shader changes, device GPU measurements and full-resolution import textures are not implemented in this phase. Main unchanged.
