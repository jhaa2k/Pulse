# Phase 29 — waveform geometry and spectrum editor
48 editable spectrum recipes. Added signed PCM waveform input from the existing provider waveform snapshot, connected line subdivision (Catmull-Rom, 1–8), repeated gradient bands and four waveform/ring designs. Signed mode bypasses magnitude smoothing and peak markers; delay still applies. Smooth curves affect LINE and WAVE_POINTS, not filled/ribbon geometry. Gallery selection is staged with Apply/Cancel; Shuffle remains immediate. Tests exercise all 48 recipes in three canvas orientations and signed wave/curve behavior. Native VEX fields persist with defaults for older projects. No device shader or exported visual parity test has been executed. Main unchanged.

Follow-up: case-insensitive nested segment/shape names and numeric scalar measures are supported; malformed non-finite HSLA and measures fall back safely. Added portrait 720p waveform + glow + motion trail MP4 instrumentation test checking track dimensions and non-black decoded pixels. The test is compiled by CI, not executed on a device yet.
