# Phase 64 — legacy image and text asset compatibility

Inspected eight supplied scene.json archives: 103 Image layers, 26 nonempty image masks, five blurred borders, four Text layers (two use {TimeCurrent}, internal_0/internal_2 font IDs). Native ARGB and HSLA legacy image color fields now both parse and update on export, retaining integer-vs-HSLA representation. Legacy writer also updates blur divider, blurred border and auto color-key settings. Preserve built-in typeface IDs separately from file URIs, use Roboto as an explicit substitute when original font is not available, retain native font selections in VEX and legacy writer, and fail clearly for missing explicitly bundled fonts. Resolve legacy time tokens without rewriting tokens inside track metadata. Invalidate cached artwork blurs when source texture is replaced. Four CPU tests added. No exact original font mapping, generated album art algorithm, animated image speed, or device rendering comparison in this phase. Main unchanged.
