# Phase 15 recovery
Android AtomicFile primary saves with last valid previous version, bounded project IDs and load sizes, active-project marker, recovery as separate project, deletion of associated backup and autosave, coalesced pending saves, final best-effort ViewModel flush, selection and undo reset after deletion. Backup is local, not a cloud backup. Device process-death and storage-failure testing still required.

Playback: asynchronous album-art loading with generation checks, 20 MB compressed artwork limit, persisted repeat/shuffle/volume, process-scoped monotonic sleep timer independent of editor ViewModel, playback error display. Sleep timer is not an exact alarm and cannot survive process death. Metadata extraction during bulk import still synchronous. True overlap crossfade not implemented; gapless depends on Media3 and device codecs. Regression test for countdown math; actual storage recovery and physical playback require testing. Not a signed production release.
