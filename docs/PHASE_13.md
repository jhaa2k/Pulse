# Phase 13
Native procedural grid, checker, rings, plasma and starfield in image shader. Pattern uses the existing two gradient colors with independent density, mix and speed. Feathered circle, rectangle, diamond and linear aperture with size, center, feather and inversion; mask geometry uses normalized texture coordinates. Shape radius, star ratio, spin and audio radius/stroke pulses. Layer time range and linear fades on source-track time, including trimmed exports; hidden/timed-out particles do not simulate until visible again. Group labels are searchable metadata, not nested layer groups. Layer transfer keeps IDs and keyframes and rejects cycles even for hidden layers. Three new editable layer recipes. Existing native VEX serializes defaults; legacy VIZ does not retain new properties. GLES2 shader execution and GPU performance need on-device testing; true overlap crossfade and continuous video decoding remain incomplete.
