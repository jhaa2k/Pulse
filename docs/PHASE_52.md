# Phase 52 — animation controls
19 new image, text and RGB effect tracks (49 total property types across layers, including six transforms). Timeline zoom/scroll and playhead centering, tap to select, selected-value reads, selection follows successful move, 20-keyframe pages. Four additional transform recipes. Image blur requires blur enabled; other effect properties require their relevant modes. Integer font size and blur radius are rounded; animated typography can regenerate textures and increase cost. Native VEX tracks only. Physical device/UI performance remains unverified. Main unchanged.
