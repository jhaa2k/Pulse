# Phase 19 — reusable layer styles and diagnostics

32 named local layer presets retain native layer settings, transform, timing and keyframes. Instantiation generates new layer IDs, remaps keyframe targets, and substitutes a valid audio provider for missing indices. Imported image/video becomes album art, external font/mask/sprite assets are not embedded, composition-referencing layers are excluded (use full VEX archive). Same-name saves replace prior entries. Search/add/delete in Presets; save in quick tools. Optional preview diagnostics report callback FPS, CPU submission time, preview dimensions, reachable compositions, visible layers and approximate bitmap/FBO allocations; not total GPU memory or GPU execution time and excludes codec and driver allocations. Preview submits newest scene on a cadence even after the last change; continuous mode requests frames while active. Added portable preset and frame counter tests. Actual Android device UI, decoder, GPU and export testing remain necessary. No true overlap crossfade or signed release. Main unchanged.
